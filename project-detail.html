Overview

What TimeFlow Does

TimeFlow lets you log time entries against projects, then turns those entries into reports you can actually use, without needing to touch a spreadsheet. It was built as a complete, shipped desktop product rather than a code-along tutorial. Designing the data model, building the UI, and packaging a working release.

The focus was on getting the fundamentals right, a clean data layer with Entity Framework Core, a local SQLite database so the app runs fully offline, and reporting logic that's kept separate from the UI so it stays easy to extend.
